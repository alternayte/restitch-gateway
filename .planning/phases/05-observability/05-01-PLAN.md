Create new internal/observability package with request ID functionality:

1. Add github.com/oklog/ulid/v2 dependency for ULID generation

2. Create requestid.go with:
   - `type contextKey string` for type-safe context keys
   - `const RequestIDHeader = "X-Request-ID"` for header name
   - `func NewRequestID() string` - generates ULID using crypto/rand entropy source
   - `func GetRequestID(ctx context.Context) string` - extracts request ID from context, returns empty string if not present
   - `func RequestIDMiddleware(next http.Handler) http.Handler` - middleware that:
     - Checks for existing X-Request-ID header, uses it if present (26 char ULID check optional)
     - Generates new ULID if no header present
     - Stores request ID in context
     - Sets X-Request-ID response header with the ID
     - Calls next handler with enriched context

3. Create requestid_test.go with tests for:
   - NewRequestID returns valid 26-char ULID
   - GetRequestID returns empty for context without ID
   - Middleware honors incoming X-Request-ID
   - Middleware generates ULID when no header present
   - Middleware sets response header

Per CONTEXT.md: ULID format (26 chars, time-sortable, collision-safe), honor incoming X-Request-ID if present.
