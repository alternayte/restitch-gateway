Create response builder that evaluates the response template with step results.

**response.go:**
```go
// CompositionResponse is the final response to send to client
type CompositionResponse struct {
    Status      int
    ContentType string
    Body        interface{} // JSON-serializable body
}

// BuildResponse evaluates response template with step results
func BuildResponse(template *CompiledResponse, results map[string]*StepResult, req *http.Request) (*CompositionResponse, error)
```

**Implementation per CONTEXT.md decisions:**

1. **Evaluate status:**
   - If template.StatusExpr is nil, use template default (200)
   - If template.StatusExpr exists, evaluate expression (e.g., "steps.create.status")
   - Result must be int

2. **Evaluate body template recursively:**
   - Template body is nested map with expression strings
   - Walk the template structure
   - For each string value containing `{{ expr }}`, evaluate and replace
   - For nested maps, recurse
   - For arrays, evaluate each element
   - Preserve structure: output mirrors template structure

   ```go
   // evaluateTemplate recursively evaluates a template structure
   func evaluateTemplate(template interface{}, env map[string]interface{}) (interface{}, error) {
       switch v := template.(type) {
       case string:
           // Check if it's an expression template
           if IsExpression(v) {
               return evaluateExpressionString(v, env)
           }
           return v, nil
       case map[string]interface{}:
           result := make(map[string]interface{})
           for key, value := range v {
               evaluated, err := evaluateTemplate(value, env)
               if err != nil {
                   return nil, err
               }
               result[key] = evaluated
           }
           return result, nil
       case []interface{}:
           result := make([]interface{}, len(v))
           for i, value := range v {
               evaluated, err := evaluateTemplate(value, env)
               if err != nil {
                   return nil, err
               }
               result[i] = evaluated
           }
           return result, nil
       default:
           return v, nil // Pass through numbers, bools, etc.
       }
   }
   ```

3. **Build environment for evaluation:**
   - Include all step results: steps.stepname.status, steps.stepname.headers, steps.stepname.body
   - Include request context: req.path, req.query, req.headers, req.body

4. **Content-Type:**
   - Use template.ContentType (defaulted to "application/json" during parsing)

**Example:**
Template:
```yaml
body:
  user: "{{ steps.user.body }}"
  orders: "{{ steps.orders.body }}"
  total: "{{ len(steps.orders.body) }}"
```

With results:
- steps.user.body = {"id": 1, "name": "Alice"}
- steps.orders.body = [{"id": 101}, {"id": 102}]

Output:
```json
{
  "user": {"id": 1, "name": "Alice"},
  "orders": [{"id": 101}, {"id": 102}],
  "total": 2
}
```

**handler.go:**

```go
// Handler handles HTTP requests for compositions
type Handler struct {
    executor *Executor
    config   *CompiledConfig
}

// NewHandler creates a new composition handler
func NewHandler(config *CompiledConfig, httpClient *http.Client) *Handler

// ServeHTTP handles an HTTP request by executing the appropriate composition
func (h *Handler) ServeHTTP(w http.ResponseWriter, r *http.Request)

// RegisterRoutes registers all composition routes with the router
func (h *Handler) RegisterRoutes(router *server.Router)
```

**Implementation:**

1. **Route registration:**
   - For each composition in config, register route based on composition.Path and composition.Method
   - Store mapping from path -> composition name

2. **Request handling:**
   ```go
   func (h *Handler) ServeHTTP(w http.ResponseWriter, r *http.Request) {
       // 1. Find composition for this path
       compositionName := h.matchComposition(r.URL.Path, r.Method)
       if compositionName == "" {
           http.NotFound(w, r)
           return
       }

       // 2. Execute composition
       ctx := r.Context()
       result, err := h.executor.Execute(ctx, compositionName, r)
       if err != nil {
           // Fail-fast error from step execution
           // Return 502 Bad Gateway with error details
           h.writeError(w, http.StatusBadGateway, err)
           return
       }

       // 3. Build response from template
       comp := h.config.Compositions[compositionName]
       response, err := BuildResponse(comp.Response, result.Steps, r)
       if err != nil {
           h.writeError(w, http.StatusInternalServerError, err)
           return
       }

       // 4. Write response
       w.Header().Set("Content-Type", response.ContentType)
       w.WriteHeader(response.Status)
       json.NewEncoder(w).Encode(response.Body)
   }
   ```

3. **Error response format:**
   - Return JSON: `{"error": "message"}`
   - Use 502 Bad Gateway for upstream failures
   - Use 500 Internal Server Error for template evaluation errors

4. **Logging:**
   - Log composition execution start/complete
   - Include request ID, path, duration
