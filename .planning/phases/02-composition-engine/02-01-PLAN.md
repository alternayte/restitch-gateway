**config.go - Define structs matching CONTEXT.md decisions:**
```go
type Config struct {
    Upstreams    map[string]Upstream    `yaml:"upstreams"`
    Compositions map[string]Composition `yaml:"compositions"`
}

type Upstream struct {
    URL string `yaml:"url"`
}

type Composition struct {
    Path     string           `yaml:"path"`     // Route path pattern
    Method   string           `yaml:"method"`   // HTTP method (defaults to GET)
    Steps    []Step           `yaml:"steps"`
    Response ResponseTemplate `yaml:"response"`
}

type Step struct {
    Name      string            `yaml:"name"`
    Upstream  string            `yaml:"upstream"`
    Path      string            `yaml:"path"`      // Expression template
    Method    string            `yaml:"method"`    // Defaults to GET
    Headers   map[string]string `yaml:"headers"`   // Defaults to empty
    Body      string            `yaml:"body"`      // Expression template for POST/PUT
    DependsOn []string          `yaml:"depends_on"` // Explicit deps (optional)
}

type ResponseTemplate struct {
    Status      interface{} `yaml:"status"`       // int or expression string
    ContentType string      `yaml:"content_type"` // Defaults to application/json
    Body        interface{} `yaml:"body"`         // Nested map with expressions
}
```

**parser.go - YAML parsing with validation:**
- ParseConfig(data []byte) (*Config, error) - parses and validates
- LoadConfigFile(path string) (*Config, error) - reads file and calls ParseConfig
- Validate parsed config: all upstreams referenced in steps must exist
- Validate step names are unique within composition
- Apply defaults: Method="GET", ContentType="application/json"

Install dependency: `go get gopkg.in/yaml.v3`

**Add to parser.go:**
- CompileConfig(cfg *Config) (*CompiledConfig, error) - takes parsed config, compiles all expressions
- CompiledConfig struct holds Config plus compiled expressions for each step and response

**CompiledConfig structure:**
```go
type CompiledConfig struct {
    Config       *Config
    Compositions map[string]*CompiledComposition
}

type CompiledComposition struct {
    Steps    map[string]*CompiledStep
    Response *CompiledResponse
}

type CompiledStep struct {
    Step         *Step
    PathExpr     *CompiledExpr // Compiled path expression
    BodyExpr     *CompiledExpr // Compiled body expression (may be nil)
    HeaderExprs  map[string]*CompiledExpr // Compiled header expressions
}

type CompiledResponse struct {
    StatusExpr *CompiledExpr // nil if status is static int
    BodyExprs  map[string]*CompiledExpr // Compiled body template expressions
}
```

**Compilation process:**
1. For each composition, for each step:
   - Compile step.Path as expression
   - Compile step.Body if non-empty
   - Compile each header value
2. For each composition response:
   - Compile status if it's a string expression
   - Recursively compile all string values in response.Body

**Error handling:** Return first compilation error with context (which step, which field).
