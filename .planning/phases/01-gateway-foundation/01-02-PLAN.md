**HealthHandler** (GATE-04):
- Returns 200 OK with JSON body
- JSON includes:
  - `status`: "healthy"
  - `uptime`: duration since server start (e.g., "2h15m30s")
  - `version`: from build-time variable (default "dev")
  - `memory`: runtime.MemStats with allocated bytes (simplified)
- Content-Type: application/json

```json
{
  "status": "healthy",
  "uptime": "2h15m30s",
  "version": "0.1.0",

    "sys_mb": 24
  }
}
```

- Returns 200 OK with `{"status": "ready"}` when server can accept traffic

- Check server's ready state (atomic.Bool set in server.go)

- Expose `SetReady(bool)` method for shutdown to toggle ready state

- Register GET /ready -> ReadyHandler

Create middleware.go with logging middleware per CONTEXT.md decisions:

**LoggingMiddleware**:
- Wraps http.Handler
- Logs after request completes (not before)
- Log fields: method, path, status, duration (ms), remote_addr
- Structured JSON format by default
- Text format when --log-format=text flag is set

JSON log example:
```json
{"time":"2026-02-03T12:00:00Z","method":"GET","path":"/health","status":200,"duration_ms":1.2,"remote_addr":"127.0.0.1:54321"}
```

Text log example:
```
2026-02-03T12:00:00Z GET /health 200 1.2ms 127.0.0.1:54321
```

Implementation:
- Create `ResponseWriter` wrapper to capture status code
- Use `time.Now()` before and after handler to calculate duration
- Write to stdout (os.Stdout) - 12-factor app pattern
- No external logging library - use encoding/json for JSON format

Create `LogFormat` type (string) and `NewLoggingMiddleware(format LogFormat) func(http.Handler) http.Handler`

Update router.go:
- Add `Use(middleware func(http.Handler) http.Handler)` method to router
- Apply middleware to all routes in ServeHTTP

Update main.go:
- Apply LoggingMiddleware to router based on --log-format flag
- Middleware should wrap the entire router

CONTEXT.md: "Structured JSON logs by default, --log-format=text option for development"
