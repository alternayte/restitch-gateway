Create client.go with properly configured HTTP client for Phase 2 composition:

**CRITICAL from research (PITFALLS.md):**
- Default MaxIdleConnsPerHost is 2 - causes 4-5x latency penalty
- MUST set MaxIdleConnsPerHost: 100
- Use single shared http.Client per upstream, NOT per request
- Always close/drain response body to return connection to pool

**Client struct:**
```go
type Client struct {
    httpClient *http.Client
}

func New() *Client {
    transport := &http.Transport{
        MaxIdleConns:        100,
        MaxIdleConnsPerHost: 100,  // CRITICAL: default is 2
        IdleConnTimeout:     90 * time.Second,
        DisableCompression:  false,
        // TLS config for HTTPS upstreams
        TLSClientConfig: &tls.Config{
            MinVersion: tls.VersionTLS12,
        },
    }

    return &Client{
        httpClient: &http.Client{
            Transport: transport,
            Timeout:   30 * time.Second,  // Default timeout, overridden per-request
        },
    }
}
```

**Methods:**
- `Do(ctx context.Context, req *http.Request) (*http.Response, error)` - execute request with context
- `Get(ctx context.Context, url string) (*http.Response, error)` - convenience GET
- Context MUST be used for request (req.WithContext) - critical for cancellation

**Helper for response body cleanup:**
```go
// DrainAndClose properly returns connection to pool
func DrainAndClose(body io.ReadCloser) {
    if body != nil {
        io.Copy(io.Discard, body)
        body.Close()
    }
}
```

This client is NOT used in Phase 1 but MUST be ready for Phase 2 composition engine.
Document clearly that callers MUST call DrainAndClose(resp.Body) after reading response.
