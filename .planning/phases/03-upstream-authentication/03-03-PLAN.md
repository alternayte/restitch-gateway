Create PassthroughStrategy implementing auth.Strategy:

Per CONTEXT.md and RESEARCH.md Open Question 3:
- Return 401 immediately if client sends no Authorization header
- Do NOT forward unauthenticated requests to upstream (security best practice)
- Forward header verbatim when present ("Bearer xyz" -> "Bearer xyz")

```go
// ErrMissingAuthHeader is returned when passthrough auth is configured
// but the client didn't provide an Authorization header.
var ErrMissingAuthHeader = errors.New("passthrough auth requires Authorization header from client")

type PassthroughStrategy struct{}

func NewPassthroughStrategy(cfg *PassthroughConfig) (*PassthroughStrategy, error) {
    // No config to validate for passthrough
    return &PassthroughStrategy{}, nil
}

func (s *PassthroughStrategy) RoundTripper(base http.RoundTripper) http.RoundTripper {
    return &passthroughRoundTripper{base: base}
}

type passthroughRoundTripper struct {
    base http.RoundTripper
}

func (rt *passthroughRoundTripper) RoundTrip(req *http.Request) (*http.Response, error) {
    // Check if client provided Authorization header
    authHeader := req.Header.Get("Authorization")
    if authHeader == "" {
        // Per CONTEXT.md/RESEARCH.md: fail immediately, don't forward unauthenticated
        return nil, ErrMissingAuthHeader
    }

    // Authorization header exists - forward verbatim
    // Clone request to be consistent with other strategies
    reqCopy := req.Clone(req.Context())
    // Header already present from original request, no modification needed
    // But we explicitly set it to ensure it survives the clone
    reqCopy.Header.Set("Authorization", authHeader)

    return rt.base.RoundTrip(reqCopy)
}
```

Note: The handler layer (composition handler) will catch ErrMissingAuthHeader and return 401 with WWW-Authenticate header. RoundTripper can only return (*http.Response, error).

Test cases:
- Client with "Authorization: Bearer xyz" -> forwarded to upstream
- Client with "Authorization: Basic abc123" -> forwarded verbatim
- Client with no Authorization header -> ErrMissingAuthHeader returned
- Original request unmodified (clone verification)

```go
// Package auth provides authentication strategies for upstream services.
//
// Passthrough Error Handling:
//
// When using passthrough authentication, the client MUST include an Authorization
// header. If missing, the RoundTripper returns ErrMissingAuthHeader.
//
// The composition handler should catch this error and return:
//   - Status: 401 Unauthorized
//   - Header: WWW-Authenticate: Bearer (or appropriate scheme)
//   - Body: {"error": "authorization header required"}
//
// This is a security best practice - don't forward unauthenticated requests
// to upstreams that expect authentication.
```

Also add helper function for error checking:

```go
// IsMissingAuthHeaderError returns true if the error indicates
// the client didn't provide required authentication.
func IsMissingAuthHeaderError(err error) bool {
    return errors.Is(err, ErrMissingAuthHeader)
}
```
